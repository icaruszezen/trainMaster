# PyTorch 构建变体：每行一个 CUDA 版本及其对应的 torch / torchvision 版本、最低驱动版本与支持的显卡架构。
#
# 这是唯一的数据源：
#   - trainer/scripts/lib/torch-variant.sh（部署脚本、裸机安装脚本）据此按驱动与显卡自动选择变体；
#   - trainer/scripts/install-torch.sh（镜像构建、裸机安装）据此安装 torch / torchvision；
#   - 训练节点（trainmaster_trainer.variants）据此诊断已安装的 PyTorch 与驱动、显卡是否匹配。
#
# 列（空白分隔）：
#   variant      变体名，即 PyTorch 官方索引的子目录名（cu130、cu126 …、cpu）
#   torch        torch 版本
#   torchvision  与之配套的 torchvision 版本
#   source       pypi：从 PIP_INDEX_URL（PyPI 或其镜像）安装默认构建，PyPI 上的 Linux 版即为该 CUDA 版本；
#                pytorch：从 PyTorch 官方索引 <TORCH_INDEX_URL>/<variant> 安装（版本号带 +<variant> 后缀）
#   cuda         构建使用的 CUDA 版本；cpu 为 -
#   min_driver   最低 NVIDIA 驱动版本（Linux，CUDA 小版本兼容所需的最低版本）；cpu 为 -
#   archs        为 x86_64 编译的计算能力（10×主版本+次版本，如 86 = 8.6）。同一主版本中次版本号
#                不小于它的显卡都能运行（如 86 也覆盖 8.9 的 RTX 40 系列）；cpu 为 -
#   min_driver_win  Windows 上的最低 NVIDIA 驱动版本（Windows 驱动的版本号与 Linux 不同）；cpu 为 -。
#                Windows 版一律从 PyTorch 官方索引安装（PyPI 上的 Windows 版 torch 只有 CPU 版），
#                编译的架构按 archs 列判断
#
# 排列顺序即自动选择的优先顺序：取第一个驱动版本满足、且支持全部显卡的变体；都不满足时退回 cpu。
# 数据来源：PyTorch 发布兼容矩阵（RELEASE.md）、各版本构建脚本中的 TORCH_CUDA_ARCH_LIST，
# 以及 CUDA Toolkit 发布说明中小版本兼容所需的最低驱动（Linux：13.x ≥ 580，12.x ≥ 525.60.13，
# 11.x ≥ 450.80.02；Windows：13.x ≥ 580，12.x ≥ 528.33，11.x ≥ 452.39）。
# 升级版本时同时核对这三处，并运行 trainer/tests 与 trainer/scripts/tests 中的测试。
#
